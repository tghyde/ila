A QR code is a method of storing data in a grid of black and white squares in a way that computers can easily read. A typical QR code is a grid. Reading each line left-to-right and reading the lines top-to-bottom (like you read a book) we can think of a QR code as a sequence of digits, each digit being 1 (for white) or 0 (for black).
