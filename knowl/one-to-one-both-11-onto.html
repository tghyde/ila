In each case, the associated matrix transformation is both one-to-one and onto. A matrix has a pivot in every row if and only if it has a pivot in every column (if and only if it has two pivots), so in this case, the transformation is one-to-one if and only if it is onto. One can see geometrically that they are onto (what is the input for a given output?), or that they are one-to-one using the fact that the columns of are not collinear.
