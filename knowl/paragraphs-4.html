Augmented Matrices and Row Operations

Solving equations by elimination requires writing the variables the plus signs and the equals signs over and over again, when all that is changing in the equations is are the coefficients. We can make life easier by extracting only the coefficients, and putting them into a box:

This is called an augmented matrix. The word “augmented” refers to the vertical line, which we draw to remind ourselves where the equals sign belongs; a matrix is a grid of numbers without the vertical line. In this notation, our three valid ways of manipulating our equations become row operations:

  • Scaling: multiply all entries in a row by a nonzero number.
    Here the notation simply means “the first row”, and likewise for etc.
  • Replacement: add a multiple of one row to another.
  • Swap: interchange two rows.
Example

The process of performing row operations on a matrix does not change the solution set of the corresponding system of linear equations.

Indeed, the whole point of these operations is to solve the equations using the elimination method.

Definition

Two (augmented) matrices are called row equivalent if one can be obtained from the other by doing some number of row operations.

So the systems of linear equations corresponding to row-equivalent matrices have the same solution set.

Recall, a system of equations with no solutions is called an inconsistent system.
