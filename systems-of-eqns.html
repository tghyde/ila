Definition(Solution sets)

  • A solution of a system of equations is a list of numbers which when substituted for the variables makes all of the equations true simultaneously.
  • The solution set of a system of equations is the collection of all solutions.
  • Solving the system means finding all solutions with formulas involving some number of parameters.

Definition

A system of equations is called inconsistent if it has no solutions. If there is at least one solution, then the system is called consistent otherwise.
